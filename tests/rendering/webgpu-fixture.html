WebGPU rendering fixture — T91

Probes navigator.gpu, requests adapter + device, runs a triangle render + a tiny compute shader if both succeed. Self-reports on window.__results__. Under v1's SwiftShader path Vulkan is explicitly disabled (see capture/streamer-page/launch.md §"Why the GPU / Vulkan flags are non-negotiable on Chromium 147"). WebGPU on Chromium 147+ requires either Vulkan or Metal — without Vulkan and on non-Apple, Dawn falls back to a software backend that is typically present but often crashes on first device request. This fixture therefore expects every probe past navigator.gpu present to fail on the v1 path; that expectation is the test signal.
